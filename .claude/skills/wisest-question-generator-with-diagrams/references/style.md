# Diagrams Generator — Style (RECONSTRUCTED, partial)

> Reconstructed from the SKILL.md summary ("words-first, KaTeX, units, vectors").
> Not the canonical file — restore yours if available.

- Words first: the worked solution must stand on its own without the diagram; the
  diagram supports, never replaces, the algebra.
- Maths rendered with KaTeX; follow the same LaTeX conventions as `references/schema.md`
  (`\\tfrac` in steps, `\\cdot`, braced exponents).
- Always label axes, units, and vectors; a diagram with unlabelled quantities is worse
  than no diagram.
- Keep the same terse step style as the text generator (see the shared style guide).
